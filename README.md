# Scratch AI Lesson Plan Template

這是一個 Codex Skill，**用於數位教學指引格式**的教案生成。

## 功能

- 只要提供課程主題，即可產生繁體中文 Scratch 教案。
- 預設適用國小五年級、三節課，每節 40 分鐘。
- 依照隨附的《指引教案格式》DOCX 範本建立橫式 A4 教案。
- 產出詳細的課程流程、教師示範、學生操作、除錯提示、評量與教師省思。
- 加入教師引導學生使用 AI 的情境、時機、關鍵提示詞與注意事項。
- 全文件可見文字預設為 12pt，並建議使用 LibreOffice 進行版面檢查。

## 使用方式

安裝此 Skill 後，直接輸入課程主題即可，例如：

> 請生成主題為「Scratch 迷宮遊戲」的教案。

若需要調整年級、科目、節數或課程時間，可在主題後一併提供。

## 目錄

- `SKILL.md`：Skill 操作規範
- `assets/指引教案格式.docx`：數位教學指引格式範本
- `references/`：預設值與範本欄位對應說明
- `agents/openai.yaml`：Skill 在 Codex 中的介面設定

## AI 使用原則

本 Skill 將 AI 定位為備課與學習鷹架工具。教學活動中應避免輸入學生個資，要求學生理解與修改 AI 建議，不直接複製完整程式，並保留必要的來源與使用紀錄。
