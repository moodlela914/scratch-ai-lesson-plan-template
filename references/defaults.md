# Default lesson-plan settings

Use these values when the user provides only a topic:

- Grade: Grade 5
- Subject: Scratch / Information Technology
- Duration: 3 lessons, 40 minutes per lesson
- Language: Traditional Chinese
- Format: the included landscape A4 `assets/指引教案格式.docx`
- Text size: 12pt for all visible text
- Project style: a concrete Scratch game or interactive project that integrates the requested concepts
- AI role: teacher preparation, supervised question-based debugging, and post-lesson reflection; never a replacement for student reasoning or authorship

If the user specifies different values, those values override the defaults. If a requested format conflicts with the supplied template, preserve the template unless the user explicitly asks for a different format.
